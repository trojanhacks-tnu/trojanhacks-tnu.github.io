# Trojan Hacks Brand Guide

## Brand

Trojan Hacks

First edition:

Trojan Hacks 2026

## Brand Personality

Trojan Hacks should feel:

- bold
- ambitious
- innovative
- technical
- energetic
- competitive
- welcoming
- student-led

## Visual Concept

Modern technology combined with subtle Trojan / Greek visual language.

Possible visual inspiration:

- Trojan helmet silhouette
- shield geometry
- arenas
- architectural geometry
- Greek key patterns
- technical grid systems
- code brackets
- laurel geometry

Use these subtly.

## Avoid

Do not use:

- cartoon Trojan characters
- cheap fantasy graphics
- generic AI robots
- random circuits everywhere
- excessive glowing neon
- excessive gradients
- cluttered layouts

## Website

The website should use:

- strong typography
- large clean sections
- good whitespace
- clear hierarchy
- subtle movement
- strong mobile design
