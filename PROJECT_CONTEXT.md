# Trojan Hacks — Project Context

## Project

Trojan Hacks is a student-led hackathon initiative at Trevecca Nazarene University in Nashville, Tennessee.

The first event is Trojan Hacks 2026.

The long-term vision is to make Trojan Hacks a recurring annual hackathon and technology-building community.
