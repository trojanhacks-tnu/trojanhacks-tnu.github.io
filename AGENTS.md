# Trojan Hacks AI Development Instructions

Before making changes to this repository, read:

1. PROJECT_CONTEXT.md
2. DECISIONS.md
3. TASKS.md
4. README.md
5. design/brand-guide.md if it exists

## Project

This repository contains the official Trojan Hacks website.

Current website:

https://trojanhacks-tnu.github.io

Hosting:

GitHub Pages

## Technology

For the initial version use:

- HTML
- CSS
- vanilla JavaScript

Do not introduce unnecessary frameworks.

Do not require:

- paid hosting
- a database
- server-side rendering
- complicated infrastructure

unless explicitly approved.

## Accuracy

Never invent:

- sponsors
- event dates
- prizes
- speakers
- partnerships
- participant numbers
- university approvals
- Google support
- MLH support

Use Coming Soon, TBD, or To Be Announced when necessary.

## Privacy

Never commit:

- passwords
- API keys
- secret tokens
- private attendee data
- confidential sponsor information
- private university documents
- private Cloud-credit links
- payment information

## Design

Trojan Hacks should feel:

- modern
- ambitious
- technical
- energetic
- premium
- student-led

Trevecca purple should be part of the visual identity.

Subtle visual inspiration may include:

- Trojan helmet geometry
- shields
- arenas
- columns
- Greek geometry
- coding syntax
- grids

Avoid:

- cartoon Trojan characters
- generic AI imagery
- random robots
- excessive neon
- excessive gradients
- clutter
- cheap Greek clip art

## Website Quality

Use:

- semantic HTML
- mobile-first responsive CSS
- accessible navigation
- good color contrast
- keyboard-friendly controls
- meaningful alt text
- clean JavaScript
- optimized images

## Before Finishing Any Coding Task

Always:

1. Review the files you changed.
2. Check for HTML errors.
3. Check browser console errors.
4. Check desktop layout.
5. Check mobile layout.
6. Check navigation.
7. Check accessibility basics.
8. Explain what changed.
9. List anything that is still unfinished.
